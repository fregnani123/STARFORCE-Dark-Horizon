````md
# Starforce: Dark Horizon 🚀

![Banner do Jogo](https://github.com/fregnani123/STARFORCE-Dark-Horizon/blob/main/public/img-git/Captura%20de%20tela%202026-05-05%20110019%20-%20Copia.png)

**Starforce: Dark Horizon** é um jogo de combate espacial estilo arcade (shoot 'em up) desenvolvido para desktop. O projeto utiliza tecnologias web modernas para entregar uma experiência de jogo fluida, com sistemas de progressão, hangar de naves e batalhas intensas.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando o poder das tecnologias web para o ambiente desktop:

- **Electron**: Framework principal para a estrutura do aplicativo desktop.
- **Node.js**: Gerenciamento de processos e backend.
- **HTML5 Canvas**: Renderização de alta performance para os gráficos 2D e mecânicas de combate.
- **CSS3**: Interfaces de usuário (HUD, Menus e Hangar) estilizadas e responsivas.
- **JavaScript**: Lógica principal do motor do jogo, colisões e IA dos inimigos.

---

## 🎮 O Jogo

O jogador assume o comando de naves avançadas em uma missão através do horizonte negro. O jogo destaca-se pelo seu sistema de **Customização no Hangar**, onde é possível gerenciar recursos para desbloquear novos chassis e melhorias de blindagem.

### Principais Características:
* **Hangar Interativo**: Gerencie atributos como Velocidade, Resistência e Energia.
* **Sistema de Loot**: Colete estrelas e recursos para upgrades.
* **Combates contra Chefes**: Enfrente naves capitais com mecânicas de escudo e múltiplas fases.
* **HUD Imersivo**: Interface de pilotagem com telemetria em tempo real.

## 🚀 Como Executar

Se você deseja testar o build atual:

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/fregnani123/STARFORCE-Dark-Horizon.git
```

### 2️⃣ Entre na pasta do projeto

```bash
cd STARFORCE-Dark-Horizon
```

### 3️⃣ Instale as dependências

```bash
npm install
```

### 4️⃣ Execute o projeto

```bash
npm start
````
